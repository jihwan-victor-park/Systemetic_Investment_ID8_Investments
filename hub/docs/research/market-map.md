# Market Map Directory

A directory of market maps and landscape reports published by VC firms and research shops — organized by category and by firm, with a freshness read on each one. Built to have one place to check the state of a market before a deal comes in, instead of re-checking the same handful of firms' blogs every time.

<MarketMap />

## Status

Test. This is a prototype for whether a maintained external market-map directory earns a permanent spot in the capability set — evaluating the format here before committing to a real update cadence. If it sticks, the source list moves into a proper data file with a refresh job instead of a hand-curated array. The [original, unstyled directory](pathname:///research/market-map-original.html) is kept as a separate static page for comparison.
